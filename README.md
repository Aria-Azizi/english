## 🌟 Overview
Grammar is the backbone of the IELTS exam, particularly the **Grammatical Range and Accuracy (GRA)** criteria. This project is not just a standard grammar book; it is a visual, strategic toolkit designed to help candidates understand *when* and *how* to use advanced tenses in Writing Task 1, Writing Task 2, and Speaking.

## ✨ Key Features
* **🎨 Visual Timelines:** Custom-coded CSS graphics to help you visualize how each tense sits on the timeline (Past, Now, Future).
* **⚖️ Active & Passive Voice:** Dedicated formulas for both voices. (Passive voice is crucial for IELTS Band 8+).
* **🚫 Band 6 Pitfalls:** Clear warnings for common mistakes, such as the "Stative Verb Trap" and timeline mismatches.
* **🎯 IELTS Strategies:** Specific, actionable use-cases for each tense mapped directly to IELTS Speaking and Writing tasks.
* **⚡ Zero Dependencies:** Built purely with HTML5 and CSS3. No frameworks, no build tools. Just open and learn.
